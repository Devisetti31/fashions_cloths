ES ETHNIC STYLES - Hero Fashion Video Directory
==================================================
Place your promotional fashion video in this directory:
- Recommended filename: hero-fashion.mp4 (or .webm)
- Target file path: frontend/public/videos/hero-fashion.mp4
- Specifications:
  * Format: MP4 (H.264 / AAC) or WebM
  * Aspect Ratio: 16:9 or 4:3
  * Resolution: 1080p (1920x1080) or 720p (1280x720) recommended for optimal web streaming
  * Audio: Autoplay is muted by default; keep file size compressed (< 10-15MB) for fast loading.

The Hero component will automatically load /videos/hero-fashion.mp4 if present,
and seamlessly fall back to the curated high-resolution campaign poster if the video is loading or missing.
